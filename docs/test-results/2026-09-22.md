## Reproducibility

To replicate this exact run:

```bash
git clone https://github.com/johnhendrickh/arus-idx.git ~/arus
cd ~/arus
cp .env.example .env && nano .env   # SECTORS_API_KEY required
docker compose up -d --build        # or .venv/bin/python -m app.server
curl http://localhost:8787/api
.venv/bin/python scripts/bt_proxy.py
```

Caveat: backtest numbers may vary ±1-2% across runs depending on which Sectors snapshot available that day (data source is daily-updated). For exact reproducibility see `data/cache/*.csv` paired with this commit SHA.
